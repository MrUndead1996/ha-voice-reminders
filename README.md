# Voice Reminders

Пользовательская интеграция Home Assistant для голосовых напоминаний. Напоминания хранятся в Home Assistant Store с миграцией схемы и сохраняются при перезагрузке. Планировщик использует одноразовые callbacks в `scheduler.py`, без поллинга: после запуска пропущенное напоминание доставляется один раз, а повторяющееся переносится на ближайшую дату в будущем.

## Возможности

- Личные списки: `view: mine` — полученные напоминания, `view: created` — созданные для других.
- Получатель может изменять, откладывать и отменять свои напоминания. Создатель чужого напоминания может его отменить, но не изменять или откладывать. Вызовы без контекста пользователя считаются системными и обходят эти проверки.
- Получателя можно указать по `user_id`, имени, username или полному имени. При неоднозначном совпадении выберите ID.
- Озвучивание через Assist satellites вызовом `tts.speak` с `announce` и необязательной фразой `preannounce`; персональные push через настроенные notify-сервисы.
- Для откладывания через уведомления используется действие `voice_reminders_snooze` и требуется HA Mobile App. Текущая реализация отправляет отдельные notify-вызовы с полями `action` и `action_data`, а не стандартный массив кнопок `data.actions`; отображение кнопок зависит от обработки этих полей notify-сервисом и не гарантировано стандартным Mobile App.
- Четыре Assist-интента с разбором русских и английских значений и дат, включая «завтра в 15:00» и «next monday»; ответы и ошибки локализованы на русский и английский.

## Установка

### Через HACS

1. В HACS откройте «Пользовательские репозитории» и добавьте URL этого репозитория с категорией «Интеграция».
2. Найдите Voice Reminders в HACS и установите интеграцию.
3. Перезапустите Home Assistant.

### Вручную

Скопируйте каталог `custom_components/voice_reminders` в `config/custom_components/voice_reminders` и перезапустите Home Assistant.

### Русские фразы Assist

При первом запуске интеграция безопасно устанавливает собственную грамматику в `<HA config>/custom_sentences/ru/voice_reminders.yaml`, откуда Home Assistant штатно загружает пользовательские предложения. Это выполняется при загрузке записи интеграции; после установки или обновления файла необходим **перезапуск Home Assistant**, чтобы Assist перечитал предложения. Настройте русский язык у Assist pipeline.

Для обновления интеграция перезаписывает только файл, совпадающий с предыдущей установленной ею версией (контрольная сумма хранится рядом в `.voice_reminders.yaml.sha256`). Если целевой файл изменён пользователем или ранее существовал без отметки интеграции, он остаётся нетронутым и в журнал записывается предупреждение. Чтобы вернуть интеграционную грамматику, сохраните пользовательский файл в другом месте и удалите конфликтующий файл: следующий запуск установит грамматику, а ещё один перезапуск загрузит её в Assist. Соседний checksum-файл не содержит пользовательских данных.

Фразы используют штатные обработчики `voice_reminders.*`, требуют авторизованный пользовательский контекст и сохраняют проверки доступа интеграции. Поддержаны создание через числовой интервал (минуты, часы, дни, недели), «через минуту/час/полчаса», сегодня или завтра в указанное время, ежедневно/еженедельно/ежемесячно в указанное время, список своих напоминаний, отмена по точному тексту и откладывание по точному тексту. Повторы начинаются в ближайшее указанное время. Фразы по дням недели, отмена всех напоминаний и создание для другого пользователя голосовой фразой не поддерживаются. Через сервисы можно создать напоминание на конкретную дату или для другого пользователя; массовой отмены и повторов по будням нет.

## Настройка

Добавьте интеграцию через «Настройки → Устройства и службы → Добавить интеграцию → Voice Reminders». Настройка через YAML не поддерживается. В форме укажите название, под которым интеграция будет отображаться в Home Assistant.

В параметрах интеграции доступны следующие поля:

- Выберите спутники флажками или включите «Использовать все спутники», чтобы автоматически учитывать новые устройства. При выключенной опции пустой выбор отключает озвучивание.
- `preannounce` — фраза перед озвучиванием.
- Для каждого пользователя выберите сервис уведомлений из списка; `None` отключает персональные уведомления. Ранее настроенные привязки сохраняются.
- `snooze_intervals` — до пяти уникальных положительных интервалов в минутах через запятую, например `5, 10, 30`.

Для озвучки нужен TTS и Assist satellites; для push нужен notify-сервис, например `mobile_app`, а для действий в уведомлениях — HA Mobile App и поддержка указанного формата действия сервисом уведомлений. Push отправляется только владельцу, для которого выбран сервис уведомлений.

## Сервисы

Примеры ниже — действия Home Assistant. Замените ID пользователей и напоминаний, даты и имена на свои. `date` в сервисах — строка ISO 8601 с часовым поясом; новая дата должна быть в будущем. ID напоминания — канонический UUID4. Допустимые статусы: `pending`, `fired`, `done`, `cancelled`. Вызов `list` возвращает объект с массивом `reminders`.

Создать напоминание по ID получателя:

```yaml
action: voice_reminders.create
data:
  text: Полить цветы
  owner_user_id: USER_ID
  date: "2030-05-20T15:00:00+03:00"
  recurrence: weekly
```

`recurrence` может быть `none` (по умолчанию), `daily`, `weekly` или `monthly`. Вместо `owner_user_id` можно указать `owner` — например, создать напоминание другому пользователю по имени:

```yaml
action: voice_reminders.create
data:
  text: Забрать посылку
  owner: Анна Иванова
  date: "2030-05-21T18:00:00+03:00"
  recurrence: none
```

Создатель берётся из контекста вызова; без него можно передать `created_by_user_id`, иначе создателем будет получатель.

Список моих ожидающих напоминаний (`view` требует контекст пользователя):

```yaml
action: voice_reminders.list
data:
  view: mine
  status: pending
```

Для созданных другим используйте `view: created`. Вместо `view` можно задать фильтр `owner: Анна Иванова` или `owner_user_id: USER_ID`; `status` необязателен. Без фильтра получателя сервис возвращает все подходящие записи.

Изменить напоминание (необходимо передать хотя бы одно изменяемое поле):

```yaml
action: voice_reminders.update
data:
  id: "123e4567-e89b-42d3-a456-426614174000"
  text: Полить все цветы
  date: "2030-05-22T15:00:00+03:00"
  recurrence: daily
  status: pending
```

Отменить:

```yaml
action: voice_reminders.cancel
data:
  id: "123e4567-e89b-42d3-a456-426614174000"
```

Отложить ожидающее напоминание на 600 секунд от его текущей даты:

```yaml
action: voice_reminders.snooze
data:
  id: "123e4567-e89b-42d3-a456-426614174000"
  delay: 600
```

Вместо `delay` можно передать `date: "2030-05-22T16:00:00+03:00"`; требуется ровно одно из этих полей, а итоговая дата должна быть в будущем.

## Assist

Интенты `voice_reminders.CreateReminder`, `voice_reminders.ListReminders`, `voice_reminders.CancelReminder` и `voice_reminders.SnoozeReminder` вызываются через Assist — голосом или через инструмент вызова интентов в инструментах разработчика. В зависимости от интента используются слоты `text`, `date`, `delay`, `id`, `view`, `status`, `owner`, `recurrence`. Для отмены и откладывания укажите ID или текст; если он не указан, интент запросит уточнение.

Примеры фраз для настройки распознавания Assist:

- «Напомни мне завтра в 15:00 полить цветы» — “Remind me to water the flowers tomorrow at 15:00”.
- «Отложи напоминание на 10 минут» — “Snooze the reminder for 10 minutes”.
- «Отмени напоминание полить цветы» — “Cancel the reminder to water the flowers”.
- «Покажи мои напоминания» — “Show my reminders”.

Русские предложения Assist входят в интеграцию и устанавливаются автоматически (см. «Русские фразы Assist»). Английские примеры требуют собственного сопоставления фраз с интентами и слотами. Относительные даты вроде «завтра в 15:00» и “next monday” также разбираются при передаче в слот `date` напрямую.

## Переход с YAML-пакета

Если раньше напоминания работали через YAML-пакет с automations/scripts в `packages`, удалите этот пакет, установите интеграцию и добавьте её через UI. Создайте напоминания заново через сервисы или интенты: данные из YAML автоматически не переносятся, новые данные хранятся в Home Assistant Store, а не в YAML.

Например, автоматизация вместо YAML-таймера может создать напоминание через сервис:

```yaml
alias: Напомнить о стирке
triggers:
  - trigger: state
    entity_id: input_boolean.washing_started
    to: "on"
actions:
  - action: voice_reminders.create
    data:
      text: Достать бельё
      owner_user_id: USER_ID
      date: "{{ (now() + timedelta(minutes=60)).isoformat() }}"
      recurrence: none
```

## Примечания

При недоступности TTS или notify ошибка записывается в журнал и не блокирует планировщик; повторная доставка не выполняется. Однократное напоминание после попытки доставки получает статус `fired`.
