# Voice Reminders

Пользовательская интеграция Home Assistant для голосовых напоминаний.
Сейчас это **каркас, черновая версия**: настройка сохраняется, но создание,
озвучивание и отправка напоминаний ещё не реализованы.

## Установка через HACS

1. В HACS откройте меню «Пользовательские репозитории» и добавьте URL этого
   репозитория с категорией «Интеграция».
2. Найдите Voice Reminders в HACS и установите интеграцию.
3. Перезапустите Home Assistant.

## Настройка

Откройте «Настройки → Устройства и службы → Добавить интеграцию», найдите
Voice Reminders и укажите название и интервал в минутах (от 1 до 1440).
По умолчанию интервал равен 30 минутам. Изменить интервал можно в параметрах
интеграции. Настройка через YAML не требуется.
